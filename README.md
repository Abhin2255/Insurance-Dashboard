# 🏥 Insurance Dashboard – Excel Data Analytics Project

## 📌 Project Overview

The **Insurance Dashboard** is an interactive data visualization project developed using Microsoft Excel. It provides a visual overview of insurance data, helping users explore relationships between insurance charges and different customer attributes.

The dashboard allows users to analyze insurance information through interactive slicers, charts, and visual reports.

## 🎯 Project Objectives

- Analyze insurance charges based on customer characteristics.
- Understand the distribution of customers by gender.
- Explore the relationship between age and insurance data.
- Compare insurance information across different regions.
- Analyze insurance charges based on smoking status.
- Create an interactive dashboard for easy data exploration.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Visualization
- Data Analysis

## 📊 Dashboard Features

### 1. Interactive Filters (Slicers)

The dashboard includes the following interactive filters:

- **Sex:** Male and Female
- **Children:** 0 to 5
- **Smoker:** Yes and No
- **Region:** Northeast, Northwest, Southeast, Southwest

### 2. Data Visualizations

The dashboard contains the following charts:

| Visualization | Description |
|---|---|
| Smoker Analysis | Compares insurance charges between smokers and non-smokers. |
| Gender Analysis | Displays the distribution of customers by gender. |
| Age Analysis | Visualizes insurance information by age. |
| Region Analysis | Compares insurance data across different regions. |
| BMI Analysis | Displays the distribution of insurance data across BMI values. |

## 📈 Key Features

- Interactive dashboard with dynamic slicers.
- Multiple chart types for data visualization.
- Gender-wise analysis.

## 🚀 How to Use

1. Download or clone this repository.
2. Open `Insurance_Dashboard.xlsx` using Microsoft Excel.
3. Navigate to the Dashboard sheet.
4. Use the slicers to filter the insurance data.
5. Explore the charts and visualizations.
6. Select different filter options to dynamically analyze the dashboard.
